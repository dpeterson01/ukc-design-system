# Presentation design review

Run this review before presenting or sharing a UKC slide deck.

1. **Compare slides at the same size.** Review a slide sorter or rendered previews to see the whole sequence. Choose a reference slide for each recurring layout. Use guides or overlay previews to check any element that appears to jump.
2. **Check elements that repeat across the deck.** Keep logos, slide numbers, timing cues, and other recurring elements aligned to the same guides wherever they appear. Check their size and spacing as well as their position.
3. **Compare slides that serve the same purpose.** Check the left edge and first visible line of titles and prompts, the typography, and the spacing between related elements. Align captions to their images and reading references to their passages. Check the rendered text because wrapping and vertical centering can shift it within the text box.
4. **Review deliberate layout changes at presentation size.** Give an image, reading, or activity the space it needs. Keep the shared guides where practical and run the revised slides in sequence to check for distracting shifts, overlap, and clipping.
